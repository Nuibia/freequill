# FreeQuill 长篇创作

启动 `long-chapter@2`，输入 `book_path`、正整数 `chapter_number` 和必要的连续性事实。Classic 模式确认章计划后起草；Fast 模式在一次委托内推进，但仍保留五路隔离验稿。

正文最多两次返修、三轮验稿，通过后只落当前章节，不自动发布、不擅自改写其他章节。

执行前读取 [Host 执行协议](references/host-protocol.md)。
