# 古言品类

启动 `genre-diagnose@2`，固定 `genre=guyan`。检查女主是否凭自身选择推进主线、困局是否逐层升级、胜利是否有代价，以及称谓和世界规则是否自洽。

本 Skill 可以独立诊断，也可被短篇或长篇 Workflow 嵌套；它不替代作品事实或用户硬约束。

Context Composer 必须显式加载 L1、古言 L2 规则与算子、`RUBRIC-GUYAN-001`，以及作品存在时的 L3。L3 只能具体化时代、身份和书级边界，不能让情感关系接管女主主线，也不能删除先验优势边界与身份秩序一致性硬门。

执行前读取 [Host 执行协议](references/host-protocol.md)。
