# premise 卡示例 + 时效信号取证卡

> 配套 `freequill-xuanti`：第①步的每条市场信号填一张**取证卡**，第④步的 premise 卡照**填写示例**填实。
> 本文件所有示例均为虚构演示，不指向任何真实平台、活动或作品。

## 一、时效信号取证卡（模板）

每条候选市场信号一张，空着不准进打分表：

```
【时效信号取证卡】
- 信号标题：
- 发布方（平台官方渠道名）：
- 发布日期（必须本月或上一个自然月）：
- 原文链接 / 证据位置：
- 命中方向（男频/女频 · 品类 · 子题材）：
- 判定：✅合格·可给市场分 ／ ❌不合格（原因：超时效窗 / 非官方来源 / 泛活动 / 无日期）
- 备注：长篇定向征文须另核对「仍在收稿期 + 明确面向长篇 + 明确列出品类」，市场分封顶 3，只代表「当前收稿准入」，不代表高热
```

### ❌ 这些一律不能当市场分

| ❌ 不合格信号 | 为什么不算 |
|----------------|------------|
| 上月之前的旧帖旧榜 | 超时效窗，哪怕当时很准——只配当历史案例 |
| 无发布日期的截图、转述、「据说最近很火」 | 无法核时，无法复核 |
| 泛奖励活动、福利门槛、奖金池 | 那是投稿路由，不是热度证明 |
| 只教写法不谈风向的官方文章 | 那是写法（craft）来源，进②不进① |
| 自己作品的「已完稿 / 已投稿 / 验稿通过」 | 不能证明擅长；擅长 = 同品类已发布作品阅读人数 ≥100 + 作品名/快照日期/人数证据 |

## 二、premise 卡填写示例（虚构）

```
【premise 卡 · 候选1】
- 一句话 premise：破产小餐馆老板能看见食客的「真实满意度」，
  靠信息差把苍蝇馆子做成排队神店
- 品类 / 子题材：男频都市脑洞 · 经营流（有写法沉淀）
- 爽点引擎：期待（被差评淹没、被同行看衰）→ 爽快（信息差精准改进，排队打脸探店博主）
- 金手指 / 强设定：看到每位食客的真实满意度数值 + 一句话原因；
  限制 = 只能看自家店、每天限三次（简单、有限制、为剧情服务）
- 开篇钩子方向：前 300 字——店里唯一的客人给了五星却再没来过；
  主角看到真实满意度「41 分：糖醋里脊太甜」，当天改配方
- 选题入口 / 市场依据：时效市场命中——某平台官方创作号《N月内容风向》
  （YYYY-MM-DD 发布）命中男频都市·经营流，原文链接见取证卡 1
- 目标平台 / 体量：短故事 / 待确认
- IP / 短剧改编适配性：强冲突·中；高共情·强；低门槛·强；可执行·强；
  人设标签「破产老板 × 读心菜单」；名场面「直播探店现场打脸」
- 护栏状态：✅有写法沉淀（男频都市脑洞，见品类写法速查）
- 适配约束：无苦情线；其余按开书前与作者对齐的硬约束核对
```

## 三、❌→✅ 对照（最常见的四种填废）

| 字段 | ❌ 废卡写法 | ✅ 合格写法 |
|------|------------|------------|
| 市场依据 | 「最近这种题材很火」 | 「《N月内容风向》YYYY-MM-DD 发布，命中男频都市·经营流，链接见取证卡」 |
| 爽点引擎 | 「主角很厉害，大家都喜欢他」 | 「期待（被看衰）→ 爽快（信息差改进→当众打脸）」 |
| 金手指 | 「什么都能看见」 | 「只看自家店、每天三次」——无限制 = 一步登天 = 后面没东西写 |
| 擅长证据 | 「我写过这类，没问题」 | 「同品类已发布作品《XX》，YYYY-MM-DD 后台快照阅读人数 N≥100」 |

判据一句话：**每个字段都要能被第三方复核**——来源查得到、日期对得上、限制说得清。复核不了的字段 = 没填。
