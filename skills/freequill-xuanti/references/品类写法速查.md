# 品类写法速查（选题决策②查写法用）

> 本文件是 `freequill-xuanti` 第②步「查写法」的最低保障：判断一个品类**能不能写好**，需要知道它的核心情绪、爽点引擎、金手指用法、开篇范式和头号雷区。
> 这里只收录本体系已有积累的 4 个品类（男频都市脑洞 / 男频玄幻 / 女频古言 / 女频现言）的**蒸馏版**；装了对应品类 skill（R4 起逐品类放出）时，以完整品类 skill 为准。
> 其它品类 = 自研品类：爽点引擎、雷区清单都得自己攒，选题打分里「写法可写性」一项降档处理。
> 写法平台中立：同一个品类，投任何平台用的是同一份写法；平台差异只在投稿环节，不在这里。

## 男频都市脑洞

**核心情绪**：期待感（被轻视的委屈）→ 爽快感（快、狠、准的爆发碾压）。命门 = **信息差 + 金手指降维**，读者要的是上帝视角的爽。

**爽点引擎（一句话）**：身份反差碾压 / 逆袭打脸，先压后打。
公式：**压**（可量化的不公，越具体越好）→ **爆**（金手指到手即兑现一次小高光）→ **反馈**（反派狼狈 + 围观震惊 + 主角有实际收获）。三步缺一不可——只压不爆是憋屈文，爆了没反馈爽感减半。

**金手指**：系统 / 神豪 / 知识降维。三原则：简单 > 复杂、有成长线、有限制（为剧情服务）。**不能一步登天**——到手即无敌，后面没东西可写。

**开篇范式**：前 300 字甩出冲突或金手指；1–2 章内金手指到手并当场兑现小高光；出场人物控制在三五人以内，读者先记住主角。

**雷区 Top**：
1. 金手指喧宾夺主、一步到位（系统比主角还像主角）；
2. 套路化开局（被分手 / 催房租 / 醉酒家暴——读者看到开头就划走）；
3. 压了不爆、爆了没反馈；
4. 主角靠犯蠢制造困境（降智 = 弃书点）；
5. 后期乱开地图、战力通胀失控。

## 男频玄幻 / 仙侠

**核心情绪**：优越感 + 逆袭。读者真正爱的是**「变强之后的优越」**——成长是手段，优越是兑现目标。

**爽点引擎（一句话）**：由弱变强、越级碾压。对比造爽：前后实力落差 × 周围人态度落差。
升级循环：目标 → 阻碍 → 提升 → 克服 → 新挑战，循环往复，每一圈都要有一次态度反转的兑现。

**金手指四原则**：简单、有扩展性、有成长性、绑定剧情。强者重生流要克制升级速度，并提前想好续命方案（满级之后写什么）。

**开篇范式**：先剧情后设定——世界观扔进情节里讲，别开篇抛境界表。第一章立主线 + 动机。废柴流：1–2 章给金手指 + 当场一次小幅反抗（不是碾压，是「不一样了」的信号）。

**雷区 Top**：
1. 绿帽（男频第一大毒点，沾即死）；
2. 圣母、憋屈不还手；
3. 上来抛设定 / 境界表铺满前三章；
4. 反派降智当垫脚石（赢得没含金量 = 不爽）；
5. 换地图断线（旧人旧线全丢，读者情感账户清零）。

## 女频古言

**核心情绪**：进阶爽 + 智斗爽 + 女性自立觉醒。恋爱甜是奖励，不能替代女主的主体性。

**爽点引擎（一句话）**：「斗」——权谋分层递进（宅 → 府 → 宫 / 朝堂），反派强度决定篇幅长度。由弱变强、打脸虐渣，每一层赢法要比上一层更高级。

**金手指**：**弱金手指铁律**——信息不对等、设定不对等可以用，但必须有限制、不能躺赢。重生文动机单一清晰：报仇 / 致富 / 改命，选一个立住，别三个都要。

**开篇范式**：重生文直接点前世遗憾 + 今生目标（一句话说清「这一世她要什么」）。代入感 = 不公平 + 对比。别堆辞藻、别配角密集出场。

**雷区 Top**：
1. 语言太现代、称谓 / 礼制穿帮（古言读者对考据敏感，一秒出戏）；
2. 女主降智制造困境；
3. 男主抢女主风头 / 男主工具人「人机感」；
4. 为斗而斗，斗完没有格局升级；
5. 书名太文艺不点题（读者刷到不知道讲什么）。

## 女频现言

**核心情绪三态**：甜 / 虐 / 爽——一章只主打一种，混着写哪头都不靠。

**爽点引擎（一句话）**：信息差拉扯（认知差 + 时间差 + 情感差），延迟释放；掉马推进关系；甜 / 酸 / 虐 → 爽闭环。

**先定位再动笔**：感情流（重苏感）vs 剧情流（重爽感），开篇定调、全书坚持到底，中途换流 = 老读者流失。

**开篇范式**：命运重大转折单刀直入；前几章 2–3 个互相关联的强钩子 + 章末留钩；约 10 章内完成第一个重要转折（参考值，不是铁律）。

**雷区 Top**：
1. 恋爱脑、依附男性完成逆袭（现言头号雷，女主必须是主体）；
2. 男主与女配有实质暧昧 = 硬死线（读者零容忍）；
3. 为虐而虐、虐点不接地气（车祸癌症失忆三件套慎用）；
4. 核心钩子释放太早（信息差攒不够就揭，拉扯感塌掉）；
5. 退潮老梗硬堆（追妻火葬场 / 霸总套路要用必须微创新）。

## 选题②怎么用这份速查

对候选 premise 逐个问：

1. **爽点引擎说得清吗**？用该品类的一句话引擎套你的 premise，套不上 = 品类错配或 premise 本身不成立。
2. **核心情绪对得上吗**？你的 premise 承诺的情绪，是不是这个品类读者的主粮？（例：在男频脑洞里写温润守护 = 情绪错配。）
3. **头号雷区避得开吗**？premise 里天然带雷（如男频写感情背叛线）= 一票否决或必须改设计。
4. **金手指合规吗**？太强（一步登天）太弱（躺赢不了也爽不了）都扣分。

四项都过 = 写法可写性打高分；有一项卡死 = 降档或换方向。**查不清的品类别硬写**——自研品类的风险在选题阶段就要计入。
