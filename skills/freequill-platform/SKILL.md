# FreeQuill 投稿物料

启动 `submission@2`，输入 `book_path` 与 `platform=generic|custom|undecided`。Workflow 只在作品目录生成 `投稿物料.md` 与结构化投稿档案；具体站点名称和当前表单规则由用户在本地输入，不随公开包分发。

无法确认的当前平台字段必须标成待核验；不得承诺签约、收益或流量。登录、上传、发布、签约和付费永远不属于本 Skill 的 side effect。

执行前读取 [Host 执行协议](references/host-protocol.md)。
